Конспект по множествам в Python (сокращенно):

**Что такое set:**  
- Неупорядочная коллекция уникальных элементов.  
- Можно включать разные типы, только хэшируемые.  

**Создание:**  
- `{}` — пустое множество (на самом деле — пустой словарь, см. ниже)  
- `{1, 'a', 2.5}` — множество с элементами  
- `set()` — пустое множество или из другого iterable  

**Обратите внимание:**  
- `set()` — создание пустого множества.  
- `{}` — создаст пустой словарь, не множество!  

**Добавление элементов:**  
- `add(element)` — один элемент  
- `update([elements])` — группу элементов  

**Удаление:**  
- `remove(element)` — удаляет, если есть, иначе ошибка  
- `discard(element)` — удаляет, если есть, без ошибки  
- `pop()` — случайный элемент  

**Методы множества:**  
- `union()` или `|` — объединение  
- `intersection()` или `&` — пересечение  
- `difference()` или `-` — разность  
- `symmetric_difference()` или `^` — исключающая или  
- `issubset()` или `<=` — подмножество  
- `issuperset()` или `>=` — надмножество  
- `copy()` — копия  
- `clear()` — очистка  

**Проверка членства:**  
- `x in my_set` — есть ли элемент  

**Примеры:**  
```python
A = {1, 2, 3}
B = {2, 3, 4}
A | B  # {1, 2, 3, 4}
A & B  # {2, 3}
A - B  # {1}
A ^ B  # {1, 4}
```  

**Важно:** нельзя использовать изменяемые типы (списки, словари) внутри множества.
